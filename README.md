# Fieldcheck: an ad hoc analysis
Hallo:D
This is the starting material for Lab 1. It contains one Python script and
synthetic CSV data. You will develop this script into a structured, tested,
documented Python package during the workshop.

Copy this folder to `fieldcheck-work`, beside the `course-2026` materials folder.
Open a terminal in your copy and try:

```sh
python analysis.py
```

Use `python3` if that is your Python 3 launcher. The script uses only Python's
standard library. No package installation or project environment is needed yet.
It reads `data/tiny.csv` and writes `report.json` in the current directory.

Read the course's `docs/EXERCISE.md` for the data rules and worked answer, then
follow Lab 1 in `docs/WORKBOOK.md`. Keep the CSV inputs unchanged. Record what
happens when you run the script and the issues you find while reading it.
Look beyond numerical correctness: can you understand, reuse, test,
or run this program on another input? Do not repair it during Lab 1.

The later labs introduce functions, package structure, uv, Git, tests,
documentation, automation, and delivery. Their scaffolds are in the course
materials; they are not part of this starting script.

All data are synthetic. Do not publish this teaching project.
